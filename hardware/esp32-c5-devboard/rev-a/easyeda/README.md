# EasyEDA Pro Project Source Files

To edit the schematic and PCB design for the **ESP32-C5 DevBoard** variant:

1. Open EasyEDA Pro Desktop or Web Client.
2. Open the **ESP32-C5 DevBoard** project.
3. Export the project via **File → Export → EasyEDA (epro2)**.
4. Place the generated `.epro2` project file in this directory (`hardware/esp32-c5-devboard/rev-a/easyeda/`).
